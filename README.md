# ইস্তিকামাহ — নিয়মিত নামাজি হওয়ার সঙ্গী (MVP)

ধাপে ধাপে নামাজের অভ্যাস গড়ার Android অ্যাপ: সঠিক সময়ে কুরআনের আয়াত ও সহিহ হাদিস দিয়ে রিমাইন্ডার,
এক ট্যাপে চেক-ইন, ঈমানি যাত্রার ৪ ধাপ, ক্যালেন্ডার আর কাযার হিসাব। পরিকল্পনা: "ইস্তিকামাহ — পূর্ণ প্রোডাক্ট প্ল্যান" ডক।

## MVP-তে যা আছে

| স্ক্রিন | কাজ |
| --- | --- |
| অনবোর্ডিং | লোকেশন (৬৪ জেলা বা GPS) → দিনে কয় ওয়াক্ত পড়েন → কোন ওয়াক্ত দিয়ে শুরু → রিমাইন্ডারের তীব্রতা → অনুমতি |
| আজ | পরের/চলতি ওয়াক্ত ও বাকি সময়, ধাপ ও স্ট্রিক, ৫ ওয়াক্তের চেক-ইন, গতকালের বাকি হিসাব, আজকের আয়াত |
| ক্যালেন্ডার | মাসিক গ্রিড (প্রতিদিন ৫টা দাগ), ওয়াক্তভিত্তিক সময়মতো হার, কাযার হিসাব |
| আয়াত/হাদিস | আরবি, বাংলা, সূত্র, রিভিউ অবস্থা, যাচাইয়ের লিংক, শেয়ার |
| সেটিংস | হিসাব পদ্ধতি, মাযহাব, মিনিট সমন্বয়, হিজরি সংশোধন, তীব্রতা, দৈনিক আয়াত, টেস্ট রিমাইন্ডার |
| ব্যাটারি গাইড | ফোনের ব্র্যান্ড দেখে (Xiaomi/Realme/Vivo/Samsung) ধাপ, অটোস্টার্ট ও ব্যাটারি সেটিং-এ সরাসরি যাওয়া |

**রিমাইন্ডারের নিয়ম** (`core/Planner.kt`): ওয়াক্ত শুরুতে আমন্ত্রণ → ৪০% পার হলে ফজিলত → শেষের ২০ মিনিট আগে সতর্কতা + সাথে আশার বার্তা।
চেক-ইন করলেই বাকিগুলো বাতিল। ফোকাসের বাইরের ওয়াক্ত আর টানা ১৪ দিন সময়মতো পড়া ওয়াক্তে শুধু প্রথমটা।
নোটিফিকেশনে "বন্ধ করো" বাটন নেই — আছে "পড়েছি ✓", "জামাতে পড়েছি", "১০ মিনিট পরে"।

**ধাপ** (`core/Habit.kt`): ১. ফিরে আসা (১ ওয়াক্ত; ৭ দিনে ৫ দিন হলে উন্নতি) → ২. ভিত গড়া (প্রতি ১৪ দিনে ১ ওয়াক্ত যোগ, ফজর সবশেষে)
→ ৩. দৃঢ় হওয়া (১৪ দিনে ৫০%+ সময়মতো) → ৪. উন্নতি (৩০ দিনে ৯০%+)। ধাপ কখনো নামে না।

**প্রাইভেসি**: অ্যাপে INTERNET permission-ই নেই। সব ডেটা ফোনের SQLite-এ; Google ব্যাকআপ বন্ধ।

## কোডের গঠন

```
app/src/main/java/com/istiqamah/app/
  core/      শুধু Kotlin, Android ছাড়া — নামাজের সময়, ধাপ, স্ট্রিক, রিমাইন্ডার প্ল্যান, কন্টেন্ট বাছাই (ইউনিট টেস্টসহ)
  data/      SharedPreferences, SQLite লগ, content.json লোডার, ৬৪ জেলা
  engine/    Engine — অ্যালার্ম শিডিউল, চেক-ইন, ধাপ মূল্যায়ন
  notify/    নোটিফিকেশন, অ্যালার্ম/অ্যাকশন/বুট রিসিভার
  ui/        Compose স্ক্রিন
tools/       content_src.json (উৎস), build_content.py, lint_content.py
```

## বিল্ড

CI (`.github/workflows/build-apk.yml`): কন্টেন্ট lint → ইউনিট টেস্ট → সাইন করা release APK → GitHub Release।

রিপোজিটরিতে এই Secrets লাগবে (Adesh Ayat-এর চাবিই ব্যবহার করা যায়):

| Secret | মান |
| --- | --- |
| `KEYSTORE_BASE64` | `base64 -w0 release.jks` |
| `KEYSTORE_PASSWORD` | keystore পাসওয়ার্ড |
| `KEY_ALIAS` | ঐচ্ছিক — না দিলে `adesh` (Adesh Ayat-এর চাবি) |

নতুন চাবি বানাতে: `keytool -genkeypair -v -keystore release.jks -alias istiqamah -keyalg RSA -keysize 2048 -validity 10000`

লোকালি: `./gradlew testDebugUnitTest assembleDebug`

## কন্টেন্ট যোগ করা

1. `tools/content_src.json`-এ আয়াত (`ref`, `tags`, `short`) বা হাদিস (বাংলা, সূত্র, মান, লিংক) যোগ করুন।
   আয়াতের `short` অবশ্যই অনুবাদের হুবহু অংশ — নিজের ভাষায় লিখলে lint ব্যর্থ হবে।
2. `npm pack quran-json && tar xzf quran-json-*.tgz` তারপর `python3 tools/build_content.py --quran-dir package/dist`
3. `python3 tools/lint_content.py`
4. আলেম রিভিউ করলে `reviewed_by`-তে নাম লিখুন। **পাবলিক রিলিজের আগে** `python3 tools/lint_content.py --strict` পাস করতে হবে
   (CI-তে strict চালু করতে workflow-এ `--strict` যোগ করুন)।
